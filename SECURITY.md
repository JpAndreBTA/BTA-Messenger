# Segurança

Não publique credenciais, cookies, tokens de sessão, arquivos `.env`, chaves de assinatura ou dados de usuários neste repositório.

O aplicativo carrega somente o domínio oficial do BTA Engine e mantém a página remota em um renderer sem acesso direto ao Node.js. Problemas de segurança devem ser reportados de forma privada aos mantenedores antes de serem publicados.
